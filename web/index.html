الكلمات المفتاحية

اكتب الموضوع زي ما المشاهد هيكتبه في البحث. التحليل بياخد حوالي 102 وحدة من الـ quota، والاقتراحات مجانية.

    تحليل فيديو

    حط لينك أي فيديو: هتشوف التاجز بتاعته، وأداءه مقارنة بباقي فيديوهات قناته، وتقييم الـ SEO. (حوالي 4 وحدات)

    SEO للفيديو

    اكتب العنوان والوصف والتاجز قبل ما تنشر، والتقييم بيتحدّث وإنت بتكتب. مجاني.

    المنافسين

    ضيف القنوات اللي في نفس مجالك. البرنامج بيحدّث فيديوهاتهم كل 12 ساعة (حوالي 3 وحدات للقناة) ويطلعلك الفيديوهات اللي فرقعت.

    الفيديوهات اللي فرقعت (Outliers)

    الرقم ×3 معناه إن الفيديو جاب 3 أضعاف المعتاد لقناته. الفيديوهات اللي عمرها يوم أو اتنين لسه بتكبر.

    أحسن وقت للنشر

    الإعدادات

    المفاتيح بتتحفظ في ملف studio/.env على جهازك بس.

    المفاتيح

    سيب أي خانة فاضية لو مش عاوز تغيّرها.

    إزاي تجيب المفاتيح (مرة واحدة، 10 دقايق)

    1. افتح Google Cloud واعمل مشروع جديد (مجاني).
    2. فعّل YouTube Data API v3 و YouTube Analytics API.
    3. من Credentials اعمل API key وحطه هنا. ده كفاية للكلمات والمنافسين وتحليل الفيديو.
    4. عشان «قناتي»: من OAuth consent screen اختار External، وضيف إيميلك في Test users.
    5. من Credentials اعمل OAuth client ID نوعه Desktop app، وحط الـ Client ID والـ Secret هنا.

    لو الـ consent screen فاضل في وضع Testing، جوجل بتطلب منك تربط القناة تاني كل 7 أيام. عشان تتجنب ده اعمل Publish للتطبيق (هيطلعلك تحذير إن التطبيق مش متراجع، وده عادي لأنه تطبيقك إنت).
